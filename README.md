# Physics_project_archive


## Project Overview
This repository contains the code and data for analyzing the "Phantom Torque" effect on an asymmetric rolling body (a semicircular shell). The project includes extracting experimental data using computer vision, solving ordinary differential equations (ODEs) for theoretical comparison, and an interactive simulation dashboard.

## File Descriptions

* **`FFFF.mp4`**
  The raw experimental video recording the oscillatory motion of the semicircular shell. This footage is the basis for our empirical data extraction.

* **`tracker.py`**
  A computer vision script utilizing OpenCV. It tracks the white markers on the semicircular shell in the video to calculate the tilt angle ($\theta$) over time. It processes the video frame by frame and exports the tracking results.

* **`phantom_torque_experiment.csv`**
  The time-series dataset (Time vs. Angle) generated by `tracker.py`. This serves as the ground truth experimental data.

* **`analyze_data.py`**
  A numerical analysis script that uses `scipy.integrate.solve_ivp`. It solves the non-linear ODEs for two theoretical cases: one neglecting phantom torque and one correctly including it. It then compares the theoretical oscillation periods and trajectories against the experimental CSV data.

* **`Section7_Verification_Plot.png`**
  The output graph generated by `analyze_data.py`. It visually proves the necessity of the phantom torque term by comparing the experimental data points with the two theoretical curves.

* **`simulation.py`**
  An interactive web dashboard built with Streamlit and Plotly. It provides a live physics engine that animates the rolling body based on user-defined initial conditions. It also plots the mechanical energy deviation in real-time to demonstrate the energy conservation violation when phantom torque is ignored.
